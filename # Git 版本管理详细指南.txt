# Git 版本管理详细指南

## 1. Git 简介

Git 是目前最流行的分布式版本控制系统，能够有效管理项目的历史版本，支持多人协作开发。通过 Git，你可以随时保存、回退、对比和恢复代码。

---

## 2. 基本配置

首次使用 Git，建议先配置用户名和邮箱：

```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
```

---

## 3. 初始化仓库

在项目根目录下执行：

```bash
git init
```

---

## 4. 常用操作流程

### 4.1 查看当前状态

```bash
git status
```

### 4.2 添加文件到暂存区

```bash
git add 文件名         # 添加单个文件
git add .              # 添加所有变更文件
```

### 4.3 提交更改

```bash
git commit -m "提交说明"
```

### 4.4 查看提交历史

```bash
git log
```

---

## 5. 远程仓库操作

### 5.1 添加远程仓库

```bash
git remote add origin https://github.com/你的用户名/你的仓库.git
```

### 5.2 推送到远程仓库

```bash
git push -u origin main
```

### 5.3 拉取远程仓库最新代码

```bash
git pull
```

---

## 6. 版本回退与恢复

### 6.1 查看历史提交

```bash
git log
```

### 6.2 回退到上一个版本

```bash
git reset --hard HEAD~1
```

### 6.3 回退到指定版本

找到目标 commit 的哈希值（如 a1b2c3d4），然后：

```bash
git reset --hard a1b2c3d4
```

### 6.4 撤销未提交的修改

```bash
git checkout -- 文件名
```

---

## 7. 分支管理（可选进阶）

### 7.1 创建新分支

```bash
git branch 新分支名
```

### 7.2 切换分支

```bash
git checkout 新分支名
```

### 7.3 合并分支

```bash
git merge 其他分支名
```

---

## 8. 常见问题与建议

- **每次重要修改都要 commit 并 push**，以便随时回退。
- **写清楚 commit 信息**，方便后续查找和回溯。
- **遇到异常，先用 `git log` 找到最近的正常版本，再用 `git reset --hard` 回退。**
- **多人协作时，建议使用分支开发，合并前先 pull 最新代码，解决冲突后再 push。**
